# 🕒 ساعة بتلعب — إصدار PWA للنشر على GitHub Pages

لعبة عربية لتعليم الأطفال (٦–٧ سنوات) قراءة الساعة تدريجيًا. واجهة متجاوبة للموبايل، ساعة تفاعلية، تدريبات، نجوم، نغمات، وحفظ محلي.

## رفعها على GitHub
1. أنشئ Repository جديدًا على GitHub (مثل `sa3a-bet3ab`).
2. ارفع **كل محتويات ملف ZIP مباشرة إلى جذر المستودع**؛ لا ترفع ملف ZIP نفسه ولا تضع الملفات داخل مجلد إضافي. تأكد من رفع `.github/workflows/pages.yml`.
3. من **Settings → Pages** اختر **GitHub Actions** كمصدر النشر.
4. من تبويب **Actions** انتظر اكتمال `Deploy PWA to GitHub Pages` بنجاح.
5. رابط النشر سيظهر في سجل الـ workflow أو صفحة Settings → Pages. عادةً يكون `https://USERNAME.github.io/REPOSITORY/`.
6. افتح الرابط على Android في Chrome، واتركه يحمّل مرة كاملة. من قائمة Chrome اختر **Install app** أو **Add to Home screen**.
7. افتح التطبيق من الأيقونة، ثم اختبره بعد فصل الإنترنت.

## المميزات
- ساعة SVG تفاعلية؛ يمكن تحريك العقارب بالسحب أو بالأزرار.
- تعلّم العقرب القصير والطويل والعدّ بالخمسات.
- مستويات الساعات الكاملة، الدقائق بالخمسات، والتدريب المختلط.
- تصحيح فوري، تلميحات، نجوم، سلسلة إجابات صحيحة، وإنجازات.
- حفظ التقدم والإعدادات في `localStorage` على الجهاز نفسه.
- نغمات تشجيع تولّدها Web Audio ولا تحتاج ملفات خارجية.
- نطق عربي مصري مبدئي باستخدام Speech Synthesis مع تفضيل `ar-EG` إذا كان متاحًا.
- PWA قابلة للتثبيت وتخزين ملفاتها للعمل دون اتصال بعد أول تحميل ناجح.
- لا حسابات ولا API ولا خادم خلفي ولا خدمات مدفوعة.

## ملاحظات واقعية عن الصوت
النطق ليس تسجيلًا بشريًا مصريًا مضمنًا؛ يعتمد على الأصوات التي يوفرها Android/Chrome. اختيار صوت عربي مصري طبيعي وتوافره دون إنترنت يختلف من جهاز لآخر. نغمات التشجيع مدمجة داخل اللعبة. يلزم اختبار الصوت على الهاتف المستهدف.

## الخصوصية وحدود التخزين
لا ترسل اللعبة أي بيانات إلى خادم. التقدم محفوظ على نفس المتصفح/التطبيق، وقد يضيع إذا مُسحت بيانات الموقع أو أُعيد تثبيت التطبيق.
